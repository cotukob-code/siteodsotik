# README.md — Хаб «СайтСотика»

> **Файл:** `index.html`  
> **Тип:** Однофайловое веб-приложение (HTML + CSS + JS)  
> **Цель:** Централизованный хаб для трёх проектов: сайт, донаты, аукцион.  
> **Особенность:** Полностью автономный файл без внешних зависимостей, готов к деплою на Vercel.

---

## ✅ Сильные стороны

### 1. **Единый файл — ноль зависимостей**
- Весь функционал умещается в одном `index.html`.
- Нет npm, webpack, React, фреймворков.
- Легко развернуть: просто загрузи на хостинг — работает.

### 2. **Адаптивный и красивый дизайн**
- Использованы современные CSS-возможности: `backdrop-filter`, `radial-gradient`, `mix-blend-mode`.
- Глубокая проработка визуала: свечения, блики, орбиты, сетки — создаёт "космический" эффект.
- Тёмная тема с продуманными цветами (`--bg`, `--accent`, `--glass`) — выглядит стильно и профессионально.

### 3. **Плавные анимации и интерактив**
- Анимации `hover`, `glow`, `orbit`, `grid drift` — живые, но не раздражающие.
- Поддержка `transform`, `transition`, `filter` — всё плавно и отзывчиво.
- Анимация логотипа (`logoGlow`) — отличная деталь.

### 4. **Реализован полноэкранный режим**
- Клик по колонке → полноэкранное окно с iframe.
- Закрытие по кнопке, клику вне области, или `Esc`.
- Удобная навигация между "окнами".

### 5. **Мобильная адаптация**
- Поддержка `@media` до 520px.
- На малых экранах колонки становятся вертикальными.
- UI остаётся читаемым и кликабельным.

### 6. **Чистый и понятный JavaScript**
- Простой, но эффективный код:
  - Открытие/закрытие окон по `data-` атрибутам.
  - Обработка клавиши `Escape`.
  - Без лишнего — только то, что нужно.

### 7. **Готов к деплою**
- Комментарии указывают: *«замени src на боевой URL при деплое»* — это признак зрелого подхода.
- Подходит для Vercel, Netlify, GitHub Pages.
